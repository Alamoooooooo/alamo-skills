## 题目要求

**Q1（形状推导）** 一个小网络：`x:(N,4)`、`W1:(4,8)`、`b1:(8,)`、`W2:(8,3)`、`b2:(3,)`。
写出下面每一步结果的形状：

```
z1 = x @ W1
a1 = z1 + b1
h  = relu(a1)
z2 = h @ W2
y  = z2 + b2
```

**Q2（广播判断）** 判断下列加法能否广播，能的话写出结果形状，不能的话说明卡在哪：
- (a) `(2,3,4) + (3,1)`
- (b) `(2,3,4) + (4,3)`

**Q3（点积本质）** 用一句话 + 一个式子说明：`z1` 的第 `j` 列（即 `z1[:, j]`）是怎么算出来的？它和 `W1` 的第 `j` 列是什么关系？

**Q4（讲回来·线性组合）** 给一个聪明但没学过线代的小孩，用大白话解释「线性组合」是什么，并举一个生活中的类比。

**Q5（讲回来·权重形状）** 解释两件事：
1. 为什么权重矩阵写成 `(in, out)` 而不是 `(out, in)`？
2. 偏置 `b1` 为什么是 `(out,)` 而不是 `(in,)`？
