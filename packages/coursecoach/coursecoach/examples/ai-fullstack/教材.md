**Q1（形状推导）** 一个小网络：`x:(N,4)`、`W1:(4,8)`、`b1:(8,)`、`W2:(8,3)`、`b2:(3,)`。
写出下面每一步结果的形状：

```
z1 = x @ W1
a1 = z1 + b1
h  = relu(a1)
z2 = h @ W2
y  = z2 + b2
```

**Q2（广播判断）** 判断下列加法能否广播，能的话写出结果形状，不能的话说明卡在哪：
- (a) `(2,3,4) + (3,1)`
- (b) `(2,3,4) + (4,3)`

**Q3（点积本质）** 用一句话 + 一个式子说明：`z1` 的第 `j` 列（即 `z1[:, j]`）是怎么算出来的？它和 `W1` 的第 `j` 列是什么关系？

1. 为什么权重矩阵写成 `(in, out)` 而不是 `(out, in)`？

## 阶段 3 · Transformer 精读（2.5 周，核心起点）

| 资源 | 类型 | 补什么缺口 | 代价 | 日期 |
|:--|:--|:--|:--|:--|

| [RoFormer：Rotary Position Embedding](https://arxiv.org/abs/2104.09864) | 论文 | RoPE 一手推导：为什么旋转后内积只依赖相对位置 | 需旋转矩阵直觉；重点第 3 节；3–4h | 2021-04，v5 2023-11 |
| [Rotary Embeddings: A Relative Revolution（EleutherAI）](https://blog.eleuther.ai/rotary-embeddings/) | 博客 | 论文看不懂时的几何补充 + GPT-NeoX 高效实现 | 免费；需三角与复数；2h | 2021-04 |
| [On Layer Normalization in the Transformer Architecture](https://arxiv.org/abs/2002.04745) | 论文 | 证明 Post-LN 初始化时输出层梯度过大、必须 warmup；Pre-LN 可去掉 | ICML 2020；可跳过证明看结论；2–3h | 2020-02 |
| [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch) | 项目 | 手写因果自注意力 → 多头 → 完整 GPT → 训练循环（warmup / 梯度裁剪 / loss 诊断） | 免费；124M 需 batch=2 + 梯度累积；完整预训练需租卡 | 代码持续更新至 2026-10 |

**最容易踩的坑**：看懂 attention 公式就以为看懂了 Transformer，跳过 mask 的 `-inf`、`1/sqrt(d_k)` 的方差动机、Pre-LN 与 Post-LN 的残差路径差异。结果自己实现时 loss 一开始就 NaN。
