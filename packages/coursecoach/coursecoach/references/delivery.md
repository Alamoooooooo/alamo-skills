# 交付面：产物清单、Obsidian 集成、导出与自检

本文件回答一个问题：**这门课最终能产出什么，哪些是必需的，哪些有环境依赖。**

## 1. 产物清单

| 产物 | 生成者 | 必需 | 说明 |
|---|---|---|---|
| `syllabus.md` | AI 写 / `init_course.py` / `syllabus.py` | ✅ | 权威源：节点、先修、mastery、知识点、周数 |
| `homework/hw-*.md` | AI 写（`assets/homework.template.md`） | ✅ 每节点至少一份 | 权威源：rubric、分数、复习状态 |
| `resources/资料库.md` | AI 检索后写 | 推荐 | 每条注来源、日期、用途、代价 |
| `lessons/<nid>.md` / `lessons/<nid>--<知识点>.md` | AI 写（动作篮 `lesson`） | 可选 | 讲义：整章 / 单点。文件名是硬约定，`sync.py` 按它挂链接，并预渲染成 HTML 内联进主页 |
| `课程主页.html` | `sync.py` | ✅ | 编译产物，自包含，双击可用 |
| `课程进度.md` | `sync.py` | 推荐 | Obsidian 可读的进度页 + 深链 |
| `教材.md` / `教材.docx` | `export.py` | 可选 | 大纲 + 全部作业 + 批改记录 |
| 复习提醒自动化 | `automation_update`（AI 调用） | 可选 | 每日固定时间提醒到期作业 |
| `*-课程包-*.zip` | `pack.py` | 可选 | 整目录打包分享，可带走 `scripts/` |
| Obsidian 概念卡 / 阶段笔记 | AI 按 vault 规范写 | 可选 | 只在课程放进 vault 时有意义 |

只有前两项是**课程跑起来的最低要求**。其余缺了都能降级，不会报错。

**整门课就是一个文件夹**：复制 `<course-dir>` 等于复制课程，删它等于删课程。唯一的外部依赖是可选的 Obsidian 双链笔记与复习提醒自动化，都不影响课程本身。分享前跑 `pack.py --check`，它会拦住「作业里还留着你的作答 / 批改记录」这种最常见的信息泄露。

## 2. 主页的可交互能力（编译进模板，无需额外配置）

- 左侧目录树 + 点击跳转
- 环形课时进度：Σ(周数 × mastery)，不是数节点
- 折叠大纲：默认只展开当前阶段，可全展开 / 全收起
- 知识点标签：有概念卡 → 跳 `obsidian://`（Ctrl/⌘ + 点击直达）；点击默认弹菜单「生成讲解 / 出题 / 补资料 / 筛选」
- **动作按钮 + 动作篮**：章节级「补讲解 / 出作业 / 补资料 / 本章全部知识点」、作业行「批改」、知识点菜单；选中项进右下角动作篮（`localStorage` 持久化），「复制指令」生成结构化文本交 AI 执行。纯静态页不冒充后端，只攒动作 + 拼指令 —— 协议见 `actions.md`
- **动作篮是固定浮层**：钉在右下角，只有中间的动作列表滚动，「复制指令 / 清空」始终可见；清空或改动选中项后旧指令自动作废，从空到有一次选自动展开面板
- 已有讲义时：标签前显示 📄，章节底部出现「📄 打开本章讲义」（在库里）或「📄 阅读本章讲义」（不在库里）
- **讲义三路分流**（`sync.py`）：
  1. 课程在 Obsidian 库里 → `obsidian://open?vault=<库名>&file=<相对路径>`，点一下交给 Obsidian，网页本身不跳走（库内能双链、进图谱，体验最好）；
  2. 找不到 `.obsidian`（没装 Obsidian / 课程不在库里）→ 讲义在编译时已**预渲染成 HTML 内联进主页**，点击在当前页弹出阅读面板，标题 / 表格 / 代码块 / 列表都是排好版的，Esc 或点遮罩关闭；
  3. 兜底（讲义转换失败、旧版 HTML）→ 新标签页打开原始 `.md`。

  **同一份 HTML 拷进/拷出 vault 后重跑 `sync.py` 就会自动切换**，不用手改配置。
- 锚点深链 `#<node-id>`：只展开该节点并高亮
- 三档节奏切换（冲刺 / 标准 / 长线）实时重算周次
- 搜索 + 状态筛选（未解锁 / 进行中 / 已达标）
- 深浅主题；`localStorage` 不可用时自动降级为「不记忆 UI 状态」，不白屏
- 批改徽章（及格 / 良好 / 优秀）与复习到期提示

**硬约束**：数据只从 frontmatter 来。手改 HTML 会在下次 `sync.py` 被覆盖。

## 3. Obsidian 集成（可选，不装也能用）

课程实例放进 vault（`<vault>/60-课程/<课程名>/`）时，作业与进度页直接成为笔记：可搜索、可双链、可进图谱。

- **进度页**：`sync.py` 生成 `课程进度.md`，顶部 `[🖥 在浏览器打开课程主页](file:///…)`，底部逐节点深链。Obsidian 原生可读，零插件。
- **阶段链接**：向上探测 `.obsidian` 定位 vault 根，把 `stage<N>` 节点链到 `10-阶段/Stage N *.md`。非此命名的节点（如 `m1`）自动跳过，无副作用。
- **概念卡**：`points` 写成 `{t: 标签, note: 20-概念/卡片名}` 即可精确跳转；写成纯字符串时按同名匹配，匹配不到就退化为筛选。
- **讲义深链**：`lessons/` 里的讲义在 vault 内会被编译成 `obsidian://open?vault=…&file=…`，点击在 Obsidian 里读（有排版、能双链、能进图谱）；课程在 vault 外时，同一个按钮改为**在主页里弹出阅读面板**（讲义已预渲染成 HTML，不依赖任何外部程序）。所以「把课程放进 vault」的收益是双链和图谱，不是「能不能读讲义」——后者两种环境都能。
- **HTML 直读**：Obsidian 原生不渲染 `.html`。要库内直读需社区插件（HTML Page Viewer / Vault HTML Preview），否则用系统浏览器打开。
- 别在 Obsidian 运行时改 `.obsidian/` 配置——退出时会覆盖。

## 4. 导出与交付

- `export.py --course <dir>` → `教材.md`（大纲 + 每份作业的题目 / 作答 / 批改反馈 + 资料库附录）；`--format docx` 出 Word。
- 要更精美的排版，把 `教材.md` 交给文档类 skill，不要在本 skill 里堆样式。
- 推送在线文档（腾讯文档 / 飞书）需对应连接器已连接；未连接只交付本地文件，不报错阻塞。

## 5. 定时任务：启动与重建（可选）

**先记住一件事：自动化是宿主状态，不是文件。** 它不随 `<course-dir>` 走，也不进 zip。所以换机器、复制课程、别人下载 skill 包之后，定时任务**都不存在**——这不是 bug，是这类能力的位置决定的。

推论：**别把自动化当成交付物，要当成派生物**（和 `课程主页.html` 同级）。打包时带的是"重建配方"，落地后由首次使用时自愈。

### 5.1 怎么建

规格**不要手写**，用脚本出，避免文档与实际任务之间漂移：

```bash
python <skill>/scripts/schedule.py --course <course-dir> --check        # 值不值得建
python <skill>/scripts/schedule.py --course <course-dir> --json         # 完整规格，照建
python <skill>/scripts/schedule.py --course <course-dir> --kind weekly  # 只出周更
```

脚本给出 `name / scheduleType / rrule / prompt / cwds`，agent 拿它调宿主的 `automation_update`。**幂等**：名字里带课程标题，建之前先 list 按 name 比对，已存在就跳过。

两条的分工别搞混：

| 任务 | 时间 | 只读还是写 | 干什么 |
|:--|:--|:--|:--|
| 每日复习提醒 | 20:00 | **只读** | `review.py list --json` 报到期的作业，绝不自动 `mark` |
| 前沿周更 | 周一 09:00 | **写** `syllabus.md` + 资料库 | 见 `weekly-frontier.md` |

原则：**自动化只提醒，不自动推进**。复习是否通过由用户说了算，`review.py mark` 只在他确认后执行。

### 5.2 迁移与降级

| 场景 | 做法 |
|:--|:--|
| 换机器 / 复制课程 | 进入课程时跑一次 `schedule.py --check`，缺的补建 |
| 别人下载 skill 包 | 安装说明里写清"第一条命令"，见 `weekly-frontier.md` §5 |
| 宿主不支持自动化（如 Claude Code） | **降级不报错**：`review.py list` 照样算到期，只是没人主动叫你；建议进入课程时顺带跑一次并提一句 |
| 只能用系统定时器（Windows 计划任务 / cron） | 可让脚本定时把到期清单写进 `课程进度.md` 附近的一个文件，但**它调不动模型**——只能生成"今日待复习"，做不到主动发消息 |

**做不到的事要直说**：本 skill 不能让 AI 自己醒来。能做的只有"落地时把定时任务补上"，以及"没有定时器时照样能算出到期"。

## 6. 交付前自检清单

生成或改动后逐条过一遍，别把坏页面交给用户：

- [ ] `sync.py` 末尾无 `[warn]`（缺 points / weeks / 作业）
- [ ] `课程主页.html` 双击打开，目录、环形进度、折叠、标签都在
- [ ] 无 `NaN` / `undefined` 出现在页面上（常见于 weeks 缺失导致总周数为 0）
- [ ] 深链 `#<node-id>` 能定位到正确节点
- [ ] 节点 mastery 与最新一次批改一致；`syllabus.py next` 给的建议合理
- [ ] 作业「我的作答」区未被批改脚本改动（对比批改前后文本）
- [ ] 页面里没有残留的上一门课的名字（复制骨架起新课最容易犯）

## 7. 可选：课程知识网络（放进 vault 时有意义）

课程目录只解决「学什么、学到哪、考得怎么样」。若同时要沉淀可检索的笔记，在 Phase 3 / Phase 6 顺手生成（用 Write，无脚本约束，靠判断）：

| 笔记 | 数量 | 写法约定 |
|---|---|---|
| 入口 MOC | 1 | 总览页：阶段表 + 指向各阶段与课程主页的链接 |
| 阶段笔记 | 每节点 1 | 讲清「为什么这样排、核心类比、什么时候会用到」，不复述大纲 |
| 概念卡 | 按 `points` 出现频次 | **必须短**；固定结构：一句话定义 / 直觉 / 代价与局限。密度决定图谱质量 |
| 论文笔记 | 有论文的阶段 | 只写三件事：解决什么问题 / 方法一句话 / 代价是什么。**不复述摘要** |
| 日志 | 按需 | 只写「卡在哪」，不写读后感 |

约定：双链 `[[文件名]]`；表格内写 `\|`；新笔记必须回挂，否则成孤儿；写完跑一次双链自检（收集全部文件名 → 抓 `[[ ]]` → 比对，需排除围栏代码块与行内代码）。

**这些是加分项，不是课程运行的前置条件**。用户只要「能学 + 能考」时，不要为了凑知识网络而拖长交付。

## 8. 通用性边界

本 skill 面向**任意主题**，不限于编程：语言、乐器、会计、烘焙、临床指南都能跑。不成立的只有两类：

- **必须有「可验证」的环节**：验收标准要能落到「画出来 / 做出来 / 讲回来 / 通过测试」。纯鉴赏类目标（如「想有品味」）要先把目标翻译成可观察行为，否则批改无从下手。
- **依赖实时外部系统的目标**（如「通过某平台认证」）：课程只能覆盖知识与练习，考试报名、题库时效需用户自查，资料库要标「待核实」。

## 9. 按阶段的工具编排

| 阶段 | 必用 | 可选增强 |
|---|---|---|
| Phase 1 澄清 | 提问工具（AskUserQuestion） | 用户表述模糊时先搜索摸清领域边界再问 |
| Phase 2 方案确认 | 纯对话 | 画阶段依赖图 / 周期甘特图辅助拍板 |
| Phase 3 生成 | 联网搜索（每阶段至少一次）、写文件、跑 `init_course.py` | 子 Agent 并行调研各阶段；抓官方文档原文 |
| Phase 4 出作业 | 读验收标准、写作业 md | 实跑题目代码，确保题目本身没坏 |
| Phase 5 批改 | 读 rubric 与作答、写 result JSON、跑 `grade.py` | 对代码题实际执行验证；画错因对照图 |
| Phase 6 演化 | `syllabus.py`、改资料库 | 子 Agent 深挖薄弱点领域；设复习提醒 |
| Phase 7 维护 | 跑 `sync.py` | 导出 Word/PDF 教材、发布为在线页面 |

换到没有这些工具的 agent 时，按 `SKILL.md`「换到别的 agent / 模型时」的等价表替换；缺哪个就降级哪个，别卡住。安装路径与自检见 `portability.md`。
